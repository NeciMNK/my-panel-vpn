title: Subscription edges
description: Nodes that serve this panel’s subscriptions on their own port, so
  the master’s subscription server needs no public address. Every master keeps a
  tunnel to each enabled edge over the node’s API connection; the edge forwards
  each request to the highest-priority master that answers without a server
  error, and answers 503 while no master is reachable. certId names a
  panel-managed certificate (/panel/api/certs) that the panel has already pushed
  to the node; 0 serves plain HTTP. Point the subscription domain’s DNS at the
  edge nodes and set subURI to it. All endpoints under /panel/api/subEdges.
