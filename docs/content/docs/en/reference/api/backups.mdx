title: Backups
description: 'Backups to a folder on another server over SFTP (any SSH server;
  password or private key, both stored encrypted when NODE_TOKEN_ENCRYPTION is
  on). The database is copied on its own timer and two minutes after an admin
  edit; each node’s state (its database, TLS key and certificates) on the node
  timer. The newest backups are kept, older ones deleted. A lost node is
  restored onto a fresh server in one call: the master logs in over SSH,
  installs the node from its own build, unpacks the chosen backup and points the
  node’s record (or, for a domain, its Cloudflare A record) at the new server.
  All endpoints under /panel/api/backup.'
